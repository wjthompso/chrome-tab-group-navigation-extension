# Chrome Tab Group Navigation Extension

A Google Chrome extension for moving between tab groups without hunting through collapsed groups in the tab strip.

## Status

Early scaffold — popup lists tab groups; keyboard shortcuts and richer navigation are planned.

## Load unpacked (development)

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this project folder

## Project layout

- `manifest.json` — Extension manifest (Manifest V3)
- `popup/` — Toolbar popup UI
- `background/` — Service worker for tab group APIs
- `icons/` — Extension icons (replace placeholders before publishing)
